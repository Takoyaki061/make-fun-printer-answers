One line from the office printer, finally answering back. After years of jams, cryptic error codes and thumps, the machine gets its comeback — weary, literal, faintly passive-aggressive, and counted down to the sheet. `main.py` writes that single line (1–240 characters) to `/output/entry.txt`, where the house judge compares it pairwise against the other entries.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (pass a path as the first argument to write elsewhere, e.g. `python3 main.py output/entry.txt`).
